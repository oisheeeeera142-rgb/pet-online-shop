# Pet Online Shop 🐾



## 🔗 Live Demo

👉 **[View Live Demo](https://oisheeeeera142-rgb.github.io/pet-online-shop/)**


A modern and responsive Pet Online Shopping Website developed using HTML, CSS, and JavaScript. The platform allows users to browse pet products, view product details, manage carts, register accounts,  create and manage user accounts, and complete purchases through a clean and user-friendly interface.

## Features

### Customer Features

* User Registration & Login
* Browse Pet Products
* Product Details Page
* Add to Cart
* Shopping Cart Management
* Checkout System
* User Profile Management
* Responsive Design


### Product Categories

* Dog Food
* Cat Food
* Pet Toys
* Pet Accessories
* Pet Care Products

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Local Storage
* Font Awesome
